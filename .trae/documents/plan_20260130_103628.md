# IPC 进程管理示例调整方案

## 一、创建目标

调整 `examples/process/ipc_process.php` 文件，创建三个具有不同角色的进程，实现以下功能：
1. 第一个进程：写入数据
2. 第二个进程：读取数据并展示
3. 第三个进程：向主进程写入数据
4. 主进程：读取后展示并且关闭进程

## 二、示例结构设计

### 1. 基础结构
- **依赖引入**：保持现有依赖引入
- **Worker 类定义**：创建三个新的 Worker 子类
- **辅助函数**：保留 `colorEcho()` 函数
- **主程序逻辑**：重新设计主程序流程

### 2. Worker 子类
- **WriterWorker**：负责写入数据
- **ReaderWorker**：负责读取数据并展示
- **ReporterWorker**：负责向主进程写入数据

### 3. 通信流程
- **WriterWorker** 启动后写入测试数据
- **ReaderWorker** 读取 WriterWorker 写入的数据并展示
- **ReporterWorker** 向主进程写入状态数据
- **主进程** 读取 ReporterWorker 写入的数据并展示
- **主进程** 关闭所有进程

## 三、具体实现步骤

### 1. 创建新的 Worker 子类
- **WriterWorker**：实现数据写入逻辑
- **ReaderWorker**：实现数据读取和展示逻辑
- **ReporterWorker**：实现向主进程写入数据的逻辑

### 2. 调整主程序逻辑
- **创建 IPC 实例**：使用 Queue 类型，适合多进程通信
- **创建 Process 实例**：管理三个 Worker 进程
- **添加 Worker 到 Process**：添加三个新的 Worker 实例
- **启动 Process**：启动所有 Worker 进程
- **等待进程执行**：等待所有进程完成各自的任务
- **读取并展示数据**：主进程读取 ReporterWorker 写入的数据
- **关闭进程**：主进程关闭所有进程

### 3. 数据流程
- **测试数据**：设计结构化的测试数据
- **数据传递**：确保数据在不同进程间正确传递
- **数据展示**：清晰展示数据的流动过程

## 四、技术要点

### 1. 进程同步
- 确保进程按正确的顺序执行
- 使用适当的等待时间，确保数据有足够的时间传递

### 2. 数据一致性
- 确保数据在不同进程间传递的一致性
- 处理可能的数据竞争情况

### 3. 错误处理
- 添加适当的错误处理逻辑
- 确保进程能够正常退出

### 4. 数据输出
- 使用彩色输出区分不同类型的信息
- 清晰展示数据的流动过程
- 显示进程 ID，明确数据发送和接收的进程

## 五、预期效果

运行示例后，将看到以下输出：

1. **进程启动**：
   - 主进程启动
   - 三个子进程依次启动

2. **数据写入**：
   - WriterWorker 写入测试数据

3. **数据读取**：
   - ReaderWorker 读取并展示 WriterWorker 写入的数据

4. **数据报告**：
   - ReporterWorker 向主进程写入状态数据

5. **主进程处理**：
   - 主进程读取并展示 ReporterWorker 写入的数据

6. **进程关闭**：
   - 主进程关闭所有进程
   - 所有进程正常退出

此示例将展示完整的进程间通信流程，包括数据写入、读取、报告和主进程处理的完整过程。
