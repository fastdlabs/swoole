创建 `tests` 目录，为 `src` 目录下的主要文件编写单元测试用例，测试结构保持与 `src` 结构一致。对于涉及服务实际启动的测试，仅测试启动前的数据校验和配置信息。

## 四、技术要点

### 1. 测试框架
- 使用 PHPUnit 作为测试框架
- 遵循 PHPUnit 测试规范

### 2. 测试方法
- **单元测试**：测试单个类的功能
- **集成测试**：测试类之间的交互
- **模拟对象**：使用 Mock 对象模拟依赖
- **数据提供者**：使用数据提供者测试不同场景

### 3. 测试策略
- **不实际启动服务**：对于涉及服务启动的测试，仅测试配置和准备工作
- **测试边界情况**：测试各种边界值和异常情况
- **测试代码覆盖率**：确保主要功能都有测试覆盖

### 4. 测试辅助
- **测试工具类**：创建通用的测试辅助方法
- **测试数据**：准备标准化的测试数据
- **测试环境**：确保测试环境的一致性

## 五、实现步骤

### 1. 创建测试目录结构
- 创建与 src 对应的 tests 目录结构

### 2. 编写测试用例
- 为每个主要文件编写测试类
- 实现测试方法

### 3. 配置测试环境
- 创建 phpunit.xml.dist 配置文件
- 配置测试依赖

### 4. 运行测试
- 运行完整测试套件
- 验证测试覆盖率

### 5. 优化测试
- 根据测试结果优化测试用例
- 确保测试的可靠性和稳定性

此计划将确保所有主要文件都有对应的测试用例，且测试结构与源码结构保持一致，符合用户的要求。
